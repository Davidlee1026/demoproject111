나만의 A.T 아키텍처

화면과 판단 로직을 분리해, 부상 부위와 의료 콘텐츠를 안전하게 확장할 수 있는 구조입니다.

사용자 입력 → typed InjuryState → assessment engine → 위험도 우선순위 → 결과 카드 / 의료진 요약

Frontend · Vite + TypeScript

  • src/main.ts: 화면 상태·이벤트·접근 흐름
  • src/styles.css: 반응형 카드형 UI
  • 음성·텍스트·선택형 입력
  • 모바일 우선 화면 전환

Clinical engine

  • 입력된 부위를 재질문하지 않는 context-aware flow
  • 세부 위치·유발 동작 기반 후보 3개
  • red flag 우선 severity 판정
  • RICE와 24/48/72시간 tipping point

Backend boundary

  • 현재는 로컬 순수 함수로 동작
  • 향후 Vercel Functions 연결 가능
  • API 입력·출력은 InjuryState/Assessment 타입으로 고정
  • 사용자 기록 저장과 의료진 리포트 확장 가능

안전 원칙: 후보는 확정 진단이 아니라 감별을 위한 추정입니다. 변형, 체중 지지 불가, 신경·혈관 이상, 관절 잠김이 있으면 자가 처치보다 즉시 진료를 우선합니다.
